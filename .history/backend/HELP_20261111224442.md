### Recommendation scoring

Recommendations use an explainable weighted rule-based score, not a trained machine-learning model. Default weights are configurable through the `app.recommendations.weights.*` properties (or matching `RECOMMENDATION_WEIGHT_*` environment variables): skill 0.40, category 0.15, education 0.15, experience 0.10, location 0.08, remote 0.04, eligibility 0.03, interest 0.03, and goals 0.02. The calculator normalizes by the sum of weights for dimensions with available data; missing profile information is omitted rather than treated as a mismatch. Scores express relevance only and do not predict selection or eligibility.

### Maven Parent overrides

Due to Maven's design, elements are inherited from the parent POM to the project POM.
While most of the inheritance is fine, it also inherits unwanted elements like `<license>` and `<developers>` from the parent.
To prevent this, the project POM contains empty overrides for these elements.
If you manually switch to a different parent and actually want the inheritance, you need to remove those overrides.
